# Maintaining the starter

Edit shared coding rules in the root AGENTS.md. Keep the client imports pointed at it and the Codex quick-start focused on discovery. Update the [onboarding index](../README.md) when moving a guide. Keep new examples fictional and use Trail Log consistently.

Run the [template checks](../README.md#check-the-template-itself). When changing onboarding, rehearse starting from a plain-language request without a board, following a scoped instruction, and resuming from the handoff record. Record actual client loading separately from static import checks in the PR.

The validator checks document structure and evidence links. Reviewers still check candidate identity, command results, and user-visible behavior. Historical revisions and their validation evidence are in Git and the associated pull requests.
